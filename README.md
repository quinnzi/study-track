# study-track
<br>
<br>
I didn't have enough time to make this nearly all of the things that I wanted it to be, but it's fine. I can always come back to it. The concept is basically gamifying studying but also tracking studying. I am really in need of a tracker that just allows me to track how much time I studied for each subject, and get rewarded for completing it. This is my take on that concept in an extremely limited amount of time. You are able to log your time for studying and your coin amount is on the dashboard.
<br>
<br>
<br>
- -  For studying for over 30 minutes, you get 20 coins for each extra minute.
- - Regularly its 1 coin per minute.
- - If you get 1000 coins, you can play the game that I put my blood sweat and tears into.
<br>
<br>
  - The game is made in html canvas and it's only shown when the user gets 20,000 coins. So every study session drives you to get there to see what all the fuss is about. Ingame, when you fight enemies, they tell you do go back and study, as they wisely should. 
<br>
<br>
The program uses localStorage to store your study data, so if you clear your cookies, you'll lose your data. Right now, there's only a set number of classes and a fixed type of class, but in a future iteration, I would like to add weapon upgrades with coins after 20,000 and of caurse improve the game. Most of the hours that went intot this went into game optimization, as the game is made without an engine and in pur vanialla JS. This allows for easy data transfer between the study dashboard and the game. So, they all access the same localStorgae object. In future versions, I would like to use this feature further. SO for now, the study dash is the money and the game is the product. Is that a good analogy? Thats all i have aa
